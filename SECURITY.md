# Security Policy

## Reporting a Vulnerability

Please **do not** report security vulnerabilities through public GitHub issues.

Instead, use GitHub's
[private vulnerability reporting](https://github.com/NickMoignard/go_cli_tool_template/security/advisories/new)
(Security → Advisories → Report a vulnerability).

Please include a description and impact, steps to reproduce, and the affected
commit or version. You can expect an initial response within a few days, and we
will credit you in any resulting advisory unless you prefer otherwise.

Note that this repository ships a **template** for building CLI tools; if you
find an issue in the defaults the Template encodes (not just this repo), please
say so, since the fix may need to propagate to scaffolded projects.
